# Формат локализации

Смысловые правки находятся в #95 и #96. Эта часть отдельно фиксирует формат четырёх RP-файлов: CRLF в рабочей копии и мире, UTF-8 BOM только у uk_UA и es_ES. Значения и порядок ключей при этом не меняются.

.gitattributes хранит текст в Git с каноническим LF и выдаёт .lang с CRLF при checkout; поэтому нормализация не создаёт целиком красный/зелёный diff. .editorconfig указывает редактору кодировку и окончания строк. BOM виден только в первой строке двух языков. JS, JSON и функции остаются LF.

Проверки: python tools/tests/lang_format.py, python tools/tests/lang_check.py, python tools/lang.py check, node tools/tests/localization.mjs. Для текстов нужен перезаход в мир. Новых шрифтов или аудиофайлов нет.
