# Админ-меню, время, WorldEdit и движение бота

Подготовлено с помощью Codex.

- Время остаётся суммарным за все входы. Все компоненты целые; нулевые годы, месяцы и дни скрываются, часы/минуты/секунды остаются всегда. Пример: 1 д 0 ч 2 мин 0 с. Недостающий/нечисловой play_seconds переносится из stat_playtime, без NaN.
- В карточке игрока подпись «Ограничение в чате», предупреждения выводятся как N§7/§f3. Изменение цветов относится к карточке администратора.
- Выбор игрока после кнопки «Монеты» использует полный заголовок «Меню админа >> Монеты», как форма управления монетами.
- Сводка сервера перечисляет игроков в сети с активным тегом boost:magnet, независимо от покупки или выдачи администратором. Имена отсортированы; при пустом списке показано локализованное «Нет». Список обновляется при открытии сводки.
- Значения под кнопками режима и движения бота получают §7; обычные значения больше не наследуют чёрный цвет после §r. Собственные цвета состояний Вкл/Выкл сохраняются.

## WorldEdit

Убраны искусственные ограничения 65 536 блоков и 128 блоков по стороне. Ограничения координат/высоты самого измерения, права владельца, проверка ID и одна выполняемая операция сохраняются.

План участков — генератор, без создания полного массива для огромной области. Каждая команда обрабатывает до 8×8×8 блоков. Одна временная ticking area последовательно перемещается по рабочим участкам и покрывает не больше четырёх чанков; готовность участка проверяется через getBlock с ожиданием до 200 тиков. Это применяется к снимку, заливке, копированию, вставке и отмене. Нативные команды идут по одной за тик.

Снимки сохраняют контейнеры и метаданные; отмена, остановка, обработка ошибки и выхода игрока сохранены. Память снимков и время выполнения зависят от фактического объёма. Буфер и undo живут до перезагрузки скриптов/закрытия мира. Реестр собственных ресурсов позволяет убрать остатки после перезапуска; подробности — [восстановление WorldEdit](worldedit-recovery.md). Справка обновлена во всех языках, устаревшая ошибка лимита удалена.

## Бот

Периодический прыжок при застревании на ровной поверхности удалён. В режиме повторения прыжок игрока сам по себе не вызывает прыжка бота. Обычное движение дополнено проверкой препятствия впереди, опоры и места сверху; полублоки, высокие стены и неизвестные/незагруженные блоки не вызывают принудительный прыжок. Для API 1.19.50 используется консервативная проверка известных блоков, без отсутствующих свойств isSolid/isOnGround. Нативный поиск пути сохранён.

Сложность 4 спарринга сохраняет бег с прыжком, быстрые атаки и обход противника. Во время подъёма и при приседании дополнительные прыжки не отправляются. Более низкая сложность прыгает только при препятствии.

Сохранено ручное переименование владельца bot_ai.js → bot.js. Обновлены импорты, индекс пакета, тест и README. Также сохранено размещение кнопки удаления бота и вход в мини-игры через выбор режима из рабочей папки мира.

## Проверка

tools/tests/admin_polish.mjs проверяет время, отсутствующий счёт, заголовок монет, цвета, магнит и условия прыжков. worldedit.mjs воспроизводит заливку и отмену 66 177 блоков (129×1×513), границы загрузки, один запрос за тик и остановку огромного выделения без разворачивания всего плана в память. Проверки выполняются на моках; большие области в рабочем мире автоматически не изменялись.

В клиенте после перезахода в мир проверить все поля карточки/сводки, цвета кнопок, плоскую площадку и одиночный блок перед ботом. WorldEdit сначала проверять на небольшой области в копии мира. Файлы шрифтов, аудио, level.dat и база мира не меняются.
