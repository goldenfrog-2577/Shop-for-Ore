# ⛏️ Shop for Ore by GoldenFrog

Техническая карта-симулятор для Minecraft Bedrock Edition.

**Текущая версия:** 0.2.0 (18 октября 2026), в разработке — 0.3.0. История изменений — в [CHANGELOG.md](CHANGELOG.md).

Проект сочетает в себе:
- сложную экономическую модель,
- систему прогрессии инструментов,
- полную мультиязычность.

## 🎯 Для кого эта карта?
- Игрокам, которым важны механики и прогрессия
- Разработчикам карт, изучающим Script API и функции (`.mcfunction`)

## ⚙️ Технологии
* **Основная логика**: функции `.mcfunction` (цепочки команд)
* **Скрипты**: Minecraft Script API (JavaScript) — меню, команды чата, регистрация, античит
* **Движок**: Bedrock, `min_engine_version` 1.19.50
* **Script API**: `@minecraft/server` 1.1.0-beta, `@minecraft/server-ui` 1.0.0-beta, `@minecraft/server-gametest` 1.0.0-beta
* **Перевод**: файлы `.lang` (русский, английский, украинский, испанский)

> ⚠️ Аддон использует **бета-версии** Script API времён 1.19.50. Новые версии Bedrock старые бета-модули не загружают, поэтому там скрипты (меню, чат) без переноса на современный Script API работать не будут.

## 🌟 Ключевые системы

### 🔄 1. Перерождения (ребитх)
Сделаны функцией `functions/upgrade/upgrade_rebirth.mcfunction`.
* **Условие**: доступно с 16 по 25 уровень, не больше 5 перерождений.
* **Постоянная награда**: эффект «Спешка» I–V по числу перерождений.
* **Оповещение**: сообщение всем игрокам в чат и звук при первом перерождении.
* **Сброс прогресса**: обнуляются уровень, опыт, деньги и зачарования; счётчик перерождений сохраняется.

### 🔨 2. Кирка, растущая с уровнем
Кирка под уровень игрока выдаётся сама (`functions/system/pickaxe_lvl.mcfunction`, раз в секунду) и меняется только при смене уровня или если её нет в слоте.
* **Закреплена в слоте**: компонент `item_lock` (`lock_in_slot`) — кирку нельзя выбросить или переложить.
* **Что можно копать**: 18 ступеней кирки на 25 уровней, у каждой свой список `can_destroy` — от земли до аметистового кластера.
* **Не теряется при смерти**: компонент `keep_on_death`.
* **Не ломается**: `scripts/system/tools.js` следит за прочностью и, когда игрок не копает (или износ больше 90 %), выдаёт новую целую кирку.

### 📊 3. Экономика и интерфейс
* **Автопродажа** (`functions/system/autosale.mcfunction`): игрок встаёт на золотой блок, и руда превращается в деньги и опыт с учётом бустов x2/x4.
* **Бусты и прокачка**: общие бусты x2/x4, личный «Магнит руды» (5 минут, предметы рядом летят к игроку), VIP, зачарования (эффективность до 5, удача до 3), наборы для PvP.
* **Ивенты**: «Ускорение», «Золотой дождь» и «Подарок» по таймерам; по умолчанию выключены, включаются командой `/scoreboard players set <haste|rain|gift> settings 1`.
* **Таймеры**: `tick.json` запускает только `system/system`, `system/levelup` и планировщик `system/timers`, который вызывает `timers/tN` раз в N тиков (5, 20, 40, 80, 500, 600, 3600, 4800, 6000).
* **Панели на экране**: слева — профиль, деньги, опыт, уровень, перерождения и онлайн с иконками; справа вверху — табло пака `server-ui` (название карты, идущие бусты).

### ⚔️ 4. PvP и выживание
* **PvP только на арене**: `minecraft:damage_sensor` в `entities/player.json` — урон между игроками проходит, только если у обоих тег `player:pvp` (выдаётся по координатам арены).
* **Голод только на арене**: вне арены у игрока группа компонентов с нулевым расходом голода (`server:hunger_off`), на арене — ванильная.
* **Без опыта с руд**: сферы ванильного опыта удаляются сразу; прогресс карты — своё табло `xp`.

### 🔐 5. Аккаунты и роли
* **Регистрация и вход** (`scripts/register/`): до входа чат, команды и меню недоступны; одна форма за раз.
* **Пароли** хранятся не открытым текстом, а как соль и хеш SHA-256 (теги `pws:` / `pwh:`); длина 5–32 символа. Старые открытые пароли переводятся в хеш при первом входе.
* **Роли** (`getRole()` / `hasRole()` в `DataBase.js`): Игрок → Модератор → Администратор → Владелец, каждая следующая умеет всё, что предыдущая.
  * Владелец — хост мира (тег `host`), он один. Модератора и администратора назначает он: `!role <ник> <player|moder|admin>` (тег `role:moder` / `role:admin`), `!roles` — роли игроков в сети.
  * Модератор: `!tp`, `!invis`, `!gm6`, `!clearchat`, `!kick` (только игроков с ролью ниже своей).
  * Администратор: режимы игры, `!fly`, время, бот, палочка админа, префиксы, теги, табло, меню администратора (выдаётся в 7-й слот); античит его не проверяет, режим приключения не навязывается.
  * Владелец: `!role`, `!roles`, `!wipe` и вайп в меню администратора.
  * `!help` показывает каждому только доступные ему команды. Префикс в чате (`rank:`, `!prefix`) — украшение и прав не даёт.

### 🌍 6. Локализация
* **4 языка**: русский, английский, украинский, испанский — одинаковый набор ключей во всех `.lang`.
* **Ключи перевода** по схеме `раздел.экран.элемент`, строчными, слова через `_`:
  * `menu.*` — меню игрока (`menu.shop.kits.title`, `menu.main.button.bank`, `menu.howtoplay.line.7`), `admin.*` — меню админа, `account.*` — формы входа и регистрации;
  * `chat.*` — сообщения в чат (`chat.boost.x2`, `chat.bank.error.self`, `chat.help.spawn` — описания для `!help`), `screen.*` — заголовки на экране (`titleraw`), `hud.*` — панель слева;
  * ванильные ключи (`item.*`, `tile.*`, `death.*`, `multiplayer.*` …) переопределяются под своими именами; `scoreboards.map`, `scoreboards.x2boost`, `scoreboards.x4boost` — имена строк табло справа, они хранятся в мире, поэтому не переименованы.
* **Целые фразы с параметрами**: ник, числа и т.п. подставляются в `%1$s`, `%2$s` через `"with"` (в функциях — `{"selector":"@s"}` / `{"score":…}`, в скриптах — `rawTranslate()`), а не склеиваются из кусков — каждый язык сам выбирает порядок слов.
* **Единый стиль сообщений в чате**: `иконка Метка » текст`.
  * У каждой метки свой цвет; в игре они называются `LvL UP`, `Магазин`, `Буст`, `Ивент`, `Банк`, `Промокод`, `Сервер`, `Аккаунт`, `Настройки`, `CMD`, ошибки — `✕ ERROR! » …`.
  * Текст после `»` по одному шаблону: серый `§7`, ник белым `§f`, числа и названия жёлтым `§e`, «включено/выключено» — зелёным/красным.
  * Иконки — из шрифта карты (`glyph_E1`/`glyph_2A`), те же, что в меню; к игроку обращаемся на «ты».
  * Сообщения со вставкой ключа (`%ключ`) скрипты отправляют через `tellText()` — то есть `tellraw` с переводом, а не обычным текстом.
* **Единый стиль меню**: заголовок `Раздел » иконка Подраздел`, кнопки `§8иконка Название`, под ними вторая строка (цена, ник, «[Нажми, чтобы открыть]»); цветные кнопки — только там, где цвет что-то значит. Текст перед кнопками или полем ввода заканчивается двоеточием.

## 📁 Структура репозитория
```
behavior_packs/
  main-addon-shop_for_ore/     # Пак поведения
    functions/                 # Функции (system, timers, ranks, upgrade, shop, boost, events, settings)
    scripts/                   # Script API: меню, банк, чат и команды, регистрация, античит, кирка (tools.js)
    entities/ items/ structures/
    texts/                     # Локализация названий пака
resource_packs/
  main-rp-shop_for_ore/        # Основной пак ресурсов: интерфейс, текстуры, сущности, переводы
  server-ui/                   # Пак интерфейса с табло справа вверху
```

## 🛠 Установка и разработка
Репозиторий содержит три пака — их нужно разложить по своим папкам, а не клонировать целиком в одну:

1. `behavior_packs/main-addon-shop_for_ore` → `development_behavior_packs/` (или `behavior_packs/` внутри папки мира).
2. `resource_packs/main-rp-shop_for_ore` и `resource_packs/server-ui` → `development_resource_packs/` (или `resource_packs/` внутри папки мира).
3. Подключите к миру оба пака ресурсов и пак поведения. Для Script API в настройках мира должны быть включены экспериментальные функции (переключатель «Beta APIs»).

### Что не входит в репозиторий
* **Шрифты** (`resource_packs/main-rp-shop_for_ore/font/`) — без них используется стандартный шрифт игры.
* **Звуки** (`sounds/**/*.ogg`) — `sound_definitions.json` ссылается на 4 звука (`challenge.complete`, `tnt.explode`, `glass.broke`, `music/main.theme`); без файлов они не проигрываются.
